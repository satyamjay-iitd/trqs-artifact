CYDET-cyclist is Rekall's own tutorial query (tutorial 01, "Cyclist
Detection"), ported to TrQL: a person's box intersects a bicycle's, with no
duration constraint. It is measured by papers/vldb27/suite/bench_rekall.py,
which runs Rekall's code on Rekall's released detections beside the reference
SQL and the engine -- so this row is the only one in the suite whose answer is
gated against a third system rather than two.

SD-passclose is SD-approach with a proximity requirement: the biker and the
pedestrian must come within 100 px on both axes for a second, strictly inside
the pass. CONTAINS rather than AND, because AND on interval sets is equality
and would demand the close spell occupy the whole pass. It cuts the answer from
23,206 intervals to 3,305 on the 60-video merged set -- the OVERLAP alone
constrains only relative position, so a biker on the far side of the frame
qualifies while it is left-of and above.
